# VANTAZH HUB — сайт

Статичний сайт (без фреймворків) для GitHub Pages з доменом `vantazhhub.lviv.ua`.

## Сторінки

| Файл | Сторінка |
|---|---|
| `index.html` | Головна |
| `posluhy.html` | Послуги (вісім послуг з фото, якорі `#vantazhni`, `#pidyom` тощо) |
| `tsiny.html` | Ціни + калькулятор вартості |
| `roboty.html` | Наші роботи — галерея з фільтрами та переглядом на весь екран |
| `vidguky.html` | Відгуки + форма «Залишити відгук» |
| `pro-nas.html` | Про нас |
| `kontakty.html` | Контакти + форма «Замовити дзвінок» |
| `404.html` | Сторінка «не знайдено» |

## Перед публікацією — обов’язково

1. **Відгуки** лежать у `assets/reviews.js`. Щоб додати новий, скопіюйте один блок `{ name: ..., job: ..., text: ... },` і змініть текст. Перші три показуються на головній.
2. **Калькулятор** (`tsiny.html`) рахує підйом і спуск як «кількість мішків × поверх × 10 грн», вантажники — 300 грн/год, мінімум 800 грн. Перевірте, що саме так ви рахуєте, або змініть формулу в `assets/main.js` (блок `price estimator`).
3. **Форми** надсилають заявки на `yurakovalskiy61@gmail.com` через formsubmit.co, як і раніше. Перша заявка з нового сайту прийде з листом-підтвердженням від formsubmit — його треба підтвердити.

## Як змінити тексти

Шапка, меню й підвал однакові на всіх сторінках, тому сторінки генеруються скриптом `_src/build.py`. Змініть тексти чи послуги в ньому та запустіть:

```
python3 _src/build.py
```

(потрібен Python 3 і Pillow: `pip install pillow`). Можна й правити HTML-файли напряму — тоді зміни в шапці треба повторити в кожному файлі.

## Деталі

- Шрифти Unbounded і Onest лежать у `assets/fonts` (ліцензія OFL), без залежності від Google Fonts.
- Фото переведені у WebP двох розмірів (`img/*.webp` і `img/*-s.webp`) — сторінки вантажаться в кілька разів швидше.
- Google Analytics (`G-BR3HJHEDF2`), sitemap, robots.txt, CNAME і розмітка Schema.org для Google збережені.
- Анімація переходу між сторінками («ролета») вимикається автоматично, якщо в системі ввімкнено зменшення руху.
